## Hecho para desarrolladores Lua que quieren ergonomía web moderna.

Ludi mantiene la capa de aplicación pequeña y expresiva mientras Rust se
encarga de la capa de transporte, parsing, límites y sockets.

<CardGrid>
	<Card title="API estilo Express" icon="rocket">
		Rutas, middlewares y handlers son Lua puro, con la API que ya conoces de
		Express y Fastify.
	</Card>
	<Card title="Núcleo en Rust" icon="setting">
		Un módulo nativo construido sobre hyper + tokio hace el trabajo pesado de
		HTTP: parsing rápido, límites e I/O de sockets.
	</Card>
	<Card title="Sin runtime extra" icon="approve-check">
		Sin OpenResty, sin nginx, sin runtime separado — solo `require("ludi")` y
		ejecuta tu app con cualquier intérprete de Lua.
	</Card>
	<Card title="Middlewares" icon="puzzle">
		Cadenas de middleware globales y por ruta con `next()` explícito, estilo
		Express.
	</Card>
</CardGrid>
