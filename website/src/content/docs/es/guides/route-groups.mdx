`app:group(prefix)` reúne rutas bajo un prefijo de ruta compartido — como
un Router de Express montado en una ruta, o un plugin de Fastify registrado
con `prefix`. Las rutas registradas a través del grupo reciben el prefijo
automáticamente.

La forma habitual es un callback que recibe el grupo:

```lua
app:group("/api", function(api)
    api:get("/users", function(req, res)      -- GET /api/users
        res:json({ users = {} })
    end)

    api:post("/users", function(req, res)     -- POST /api/users
        res:status(201):json({ ok = true })
    end)
end)
```

El grupo también se devuelve, así que el callback es opcional:

```lua
local api = app:group("/api")

api:get("/ping", function(req, res)            -- GET /api/ping
    res:send("pong")
end)
```

Todos los métodos de verbo (`get`, `post`, `put`, `delete`, `patch`,
`options`, `head`) y los parámetros de ruta funcionan exactamente igual que
en la app; la ruta `"/"` corresponde al propio prefijo:

```lua
app:group("/api", function(api)
    api:get("/", handler)                      -- GET /api
    api:get("/users/:id", handler)             -- GET /api/users/42
end)
```

## Middlewares de grupo

Una lista de middlewares pasada entre el prefijo y el callback se ejecuta
antes de cada ruta del grupo:

```lua
local function auth(req, res, next)
    if req.headers["authorization"] then
        next()
    else
        res:status(401):json({ error = "Unauthorized" })
    end
end

app:group("/admin", { auth }, function(admin)
    admin:get("/stats", function(req, res)     -- auth se ejecuta primero
        res:send("secret")
    end)
end)
```

`group:use` hace lo mismo, un middleware a la vez — aplica a las rutas
registradas después de la llamada:

```lua
local admin = app:group("/admin")
admin:use(auth)
admin:get("/stats", handler)
```

<Aside type="note">
	Una función sola después del prefijo es siempre el callback. Para pasar un
	único middleware sin callback, envuélvelo en una tabla —
	`app:group("/admin", { auth })` — o usa `group:use`.
</Aside>

## Anidamiento

Los grupos se anidan; los prefijos y middlewares se acumulan:

```lua
app:group("/api", function(api)
    api:group("/v1", function(v1)
        v1:get("/users", handler)              -- GET /api/v1/users
    end)
end)
```

## Orden de ejecución

<Aside type="tip">
	Middlewares globales → middlewares del grupo (del más externo al más
	interno) → middlewares de la ruta → handler.
</Aside>

Un middleware de grupo que responde sin llamar a `next()` corta la cadena
para todas las rutas del grupo — así es como el ejemplo `auth` de arriba
protege `/admin` en su conjunto.
