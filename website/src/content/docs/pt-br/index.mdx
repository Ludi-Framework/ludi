## Feito para devs Lua que querem ergonomia web moderna.

O Ludi mantém a camada de aplicação pequena e expressiva enquanto o Rust cuida
da camada de transporte, parsing, limites e sockets.

<CardGrid>
	<Card title="API estilo Express" icon="rocket">
		Rotas, middlewares e handlers são Lua puro, com a API que você já conhece do
		Express e do Fastify.
	</Card>
	<Card title="Núcleo em Rust" icon="setting">
		Um módulo nativo construído sobre hyper + tokio faz o trabalho pesado de
		HTTP: parsing rápido, limites e I/O de socket.
	</Card>
	<Card title="Sem runtime extra" icon="approve-check">
		Sem OpenResty, sem nginx, sem runtime separado — só `require("ludi")` e rode
		seu app com qualquer interpretador Lua.
	</Card>
	<Card title="Middlewares" icon="puzzle">
		Cadeias de middleware globais e por rota com `next()` explícito, estilo
		Express.
	</Card>
</CardGrid>
