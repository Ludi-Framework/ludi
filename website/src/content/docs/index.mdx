## Built for Lua developers who want modern web ergonomics.

Ludi keeps the application layer small and expressive while Rust handles the
transport layer, parsing, limits and sockets.

<CardGrid>
	<Card title="Express-style API" icon="rocket">
		Routing, middlewares and handlers are plain Lua, with the API you already
		know from Express and Fastify.
	</Card>
	<FeatureCard title="Rust core">
		<RustLogo slot="icon" width={24} height={24} />A native module built on
		hyper + tokio does the HTTP heavy lifting: fast parsing, limits and socket
		I/O.
	</FeatureCard>
	<Card title="No extra runtime" icon="approve-check">
		No OpenResty, no nginx, no separate runtime — just `require("ludi")` and run
		your app with any Lua interpreter.
	</Card>
	<Card title="Middlewares" icon="puzzle">
		Global and per-route middleware chains with explicit `next()`,
		express-style.
	</Card>
